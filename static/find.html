01 / CSPIn this search

First, make it possible.

Constraint satisfaction checks capacity, equipment, access, your exact time and reservation conflicts. A lab and its individual iMacs cannot be double-booked.

Explore the constraints ↗
02 / HILL CLIMBINGIn this search

Then, find a better fit.

Local search compares feasible placements using a stated utility score. Seeded restarts and improving moves compare the result with a simple first-fit baseline.

Compare search methods ↗
03 / A* SEARCHIn this search

Make the journey count.

A* searches an example floor graph for a low-cost route. Travel is an assumed cost; step-free requests exclude stair edges. These are not navigation measurements.

See route reasoning ↗
04 / BAYESIn this search

Be honest about uncertainty.

Bayesian inference combines an assumed prior with a hypothetical availability report. Simple search has no new report, so it keeps the resource’s prior.

Try a noisy report ↗
05 / HMMAI workspace lab

Follow a changing space.

The hidden Markov model follows an unobserved free/busy state over noisy reports. It is used when a report sequence is supplied in the workspace, not in this simple search.

Explore a report sequence ↗
06 / SEQUENTIAL DECISIONSPost-search advice

Consider the next step.

A finite-horizon belief-state model compares booking, inspecting, waiting and leaving. This separate advisor does not rank the rooms or prevent a simulation reservation.

Explore the decision model ↗

Synthetic inventory, specified probability assumptions and assumed utility values. These methods demonstrate AI reasoning; they do not measure real campus availability or guarantee a global optimum.
